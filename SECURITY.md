# Security policy

Please do not report security vulnerabilities through public GitHub issues.

Use GitHub's private vulnerability reporting for this repository. Include the
affected SDK and version, impact, reproduction steps, and any suggested
mitigation. BoxCompute will acknowledge a complete report and coordinate a fix
and disclosure timeline with the reporter.

Never include a live BoxCompute API key, customer data, or production Sandbox
contents in a report. Revoke any credential that was accidentally disclosed.
